How it works
  1. Download the template for the list (Employees, Lines, Stations or Contractors).
  2. Fill your data in the Data sheet under the heading row. Don't rename or remove the headings.
  3. Upload the file. You will see a preview of every change before anything is saved.
  4. Rows with problems are shown with their Excel row number so you can fix only those.
  5. Confirm, and the changes are saved in one go.

Employees: a new Emp ID creates a login with the default password 123. Include each supervisor in the file (or already in the system) so the workflow routing stays correct.

Lines/Stations: station names include the code, e.g. ARJANGARH (AJG).
